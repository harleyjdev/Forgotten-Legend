# Archive of Forgotten Legends

**Archive of Forgotten Legends** is an interactive Xianxia-inspired fantasy webpage built with HTML, CSS, and JavaScript. The project invites users into a mystical archive filled with forgotten myths, glowing moon gates, drifting petals, spirit energy, and ancient legend-inspired storytelling.

The webpage is designed to feel less like a normal website and more like the entrance to a hidden fantasy realm.

# Project Concept

The goal of this project is to create an immersive fantasy experience inspired by Xianxia worlds, ancient Chinese aesthetics, and magical legend archives.

The user enters through a glowing moon gate portal, surrounded by falling petals and atmospheric effects. Instead of navigating a plain webpage, the viewer feels like they are stepping into a hidden realm where stories, maps, and legends are waiting to be discovered.

# Features
Xianxia-inspired fantasy theme
Glowing moon gate entrance
Falling flower petal effects
Ancient Chinese drama-inspired portal atmosphere
Interactive legend/archive section
Fantasy map reveal concept
Custom image asset support, including moon-gate.jpg
Responsive webpage structure
Built with beginner-friendly HTML, CSS, and JavaScript
